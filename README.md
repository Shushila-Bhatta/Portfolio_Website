# Shushila Bhatta | Portfolio

Personal portfolio website of **Shushila Bhatta**, a Computer Engineering student.

## About

This site presents my education, skills, projects and contact details. It is a single static page built with HTML, CSS and JavaScript, hosted on GitHub Pages.

## Highlights

- Clean, responsive design for laptops and phones
- Light and dark mode
- Education timeline, skills and project showcase
- Interactive terminal on the home page (try typing `help`)

## Tech stack

HTML, CSS, JavaScript

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```
python3 -m http.server
```
